# Organizare utile

Folderul `utile` este pentru lucru intern si materiale auxiliare, nu pentru fisiere aruncate temporar in radacina.

## Structura

- `achizitii/` - proceduri, caiete de sarcini, oferte si clarificari pe fiecare beneficiar/proiect.
- `trevoro/` - documentatie, integrari si materiale Trevoro.
- `parteneriate/` - contracte si documente de parteneriat.
- `studii/` - materiale de curs, subiecte si raspunsuri model.
- `operational/` - fisiere tehnice nelegate de o achizitie anume.
- `proceduri/` - instructiuni operationale si note interne inca active.
- `rapoarte/` - rapoarte generate de joburi/scripts. Nu se muta fara verificarea scripturilor care le citesc.
- `social-media/` - planuri si continut text pentru social media.

## Reguli

1. Documentele oficiale trimise din firma se inregistreaza in Nexora DMS, in `Documente -> Registru evidenta`.
2. Caietele de sarcini, specificatiile primite si documentatiile de atribuire se pastreaza in `achizitii/<proiect>`, dar nu primesc numar de iesire.
3. Pozele, logo-urile si capturile se tin in `pictures/`, nu in `utile`.
4. Fisierele generate temporar se arhiveaza in `_project_archive/cleanup-<data>/`, nu se sterg direct.
5. Rapoartele automate raman in `utile/rapoarte/` cat timp exista scripturi sau dashboarduri care le pot consulta.
